## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/lab-exam.git
```

### 2. Navigate to the project directory

```bash
cd lab-exam
```

### 3. Configure the project

Configure the required database connection, environment variables, or other settings according to the project requirements.

### 4. Run the application

For a PHP-based implementation, place the project inside your web server's document root and access it through:

```text
http://localhost/lab-exam/
```
